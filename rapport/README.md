# Rapport final du projet GeoTrack

Ce dossier contient les éléments destinés à la préparation et à la production du rapport final du projet GeoTrack.

Le rapport final devra regrouper notamment :
- l'analyse du système ;
- les exigences fonctionnelles et non fonctionnelles ;
- les hypothèses et contraintes ;
- les choix et décisions architecturales ;
- les diagrammes ;
- les calculs de dimensionnement ;
- la stratégie de données ;
- la sécurité et la résilience ;
- la stratégie de tests et de validation ;
- l'observabilité ;
- la maintenance et l'évolution ;
- les captures d'écran illustrant les différentes étapes du projet ;
- le bilan des contributions des membres de l'équipe.
