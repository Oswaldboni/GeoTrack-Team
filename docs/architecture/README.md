# Architecture du système GeoTrack

Ce dossier contient les documents relatifs à l'architecture du système GeoTrack : choix architecturaux, composants, interactions, décisions techniques, compromis et solutions rejetées.

Les fichiers sont regroupés par préfixe d'User Story. Les principales décisions sont JSON pour le contrat de télémétrie, Kafka pour le découplage, WebSocket pour la diffusion filtrée, Leaflet pour la carte, et Prometheus, Loki, Grafana et Alertmanager pour l'observabilité.
