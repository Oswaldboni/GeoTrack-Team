# Maquettes Figma GeoTrack

Ce dossier contient les références et exports des maquettes haute fidélité du système GeoTrack.

Les interfaces prévues comprennent notamment :
- la carte principale de suivi des véhicules ;
- le panneau de détails d'un véhicule ;
- le tableau de bord analytique ;
- les écrans nécessaires au parcours utilisateur principal.
